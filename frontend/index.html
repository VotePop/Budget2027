Simulateur Budget France — vue par décile

Moteur macro-budgétaire france-budget-simulateur (AGPL-3.0, Cyril Turkieh) — instance officielle francebudget.fr. Cette page ajoute une couche non présente dans le projet d'origine : la ventilation de chaque mesure par décile de niveau de vie (mêmes sources que le classeur Simulateur_Impact_Menages.xlsx de ce projet). Voir la note en bas de page pour les mesures non ventilables et les limites de rapprochement.

Méthode : le moteur original calcule le delta Md€ net de chaque mesure (recettes − dépenses, 1ère année d'entrée en vigueur) ; cette page ne recalcule pas ce delta, elle le reprend tel quel et le répartit selon nos propres clés de décile sourcées (CPO/Boutchenik 2015, DG Trésor Trésor-Éco n°371, DREES, Insee — voir le classeur Excel du projet pour le détail complet). Les mesures sans clé de décile sourcée de notre côté (fraude, éducation, transition écologique...) restent volontairement non ventilées plutôt que de recevoir une hypothèse inventée.
